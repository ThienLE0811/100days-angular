0
constructor() Khởi tạo class JS, DI injection. (Chưa nhận @Input)

2

Gọi API, khởi tạo dữ liệu chính. Chạy duy nhất 1 lần.
↓
3
ngDoCheck() <5% Rất ít dùng

ngAfterViewInit() 60% Khá hay dùng

Cú Pháp Chuẩn Triển Khai Hooks

1. Core Hooks (OnInit, OnDestroy) 
export class MyComponent implements OnInit, OnDestroy {
  private sub?: Subscription;

  ngOnInit(): void {
    // 1. Gọi API hoặc nạp dữ liệu
    this.sub = this.api.getData().subscribe();
  }

  ngOnDestroy(): void {
    // 2. Dọn dẹp chống memory leak
    this.sub?.unsubscribe();
  }
}
2. Input Changes (OnChanges) 
ngOnChanges(changes: SimpleChanges): void {
  if (changes['userId']) {
    const cur = changes['userId'].currentValue;
    this.loadUserDetails(cur);
  }
}
3. DOM View Ready (AfterViewInit) 
@ViewChild('myCanvas') canvas!: ElementRef;

ngAfterViewInit(): void {
  // Khởi tạo thư viện đồ họa hoặc focus DOM
  new Chart(this.canvas.nativeElement, {...});
}
