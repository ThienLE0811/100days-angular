Property Binding [property]="expression"

Gán giá trị từ class vào property của DOM Node hoặc Component

One-Way (Class ➔ DOM)
Trích dẫn Day 003: "Dấu ngoặc vuông [property]="expression" báo cho Angular gán giá trị của biểu thức vào thuộc tính của DOM Object. Khi dữ liệu ở class đổi, DOM tự cập nhật."

💡 Lưu ý: Khi sửa chữ trong ô [value] ở trên, giá trị user.name trong class chưa đổi vì Property Binding chỉ truyền 1 chiều từ TS class ra DOM!

Two-Way Data Binding [(ngModel)]

Đồng bộ hai chiều tức thời giữa TypeScript class và Template view (Banana in a box)

Two-Way (Class ⇄ View)
Trích dẫn Day 003: "Two-way binding chính là kết hợp của binding dữ liệu từ class ra template thông qua property binding, và từ template vào class thông qua event binding: [(ngModel)]="user.name"."
🔬 Bản chất tách rời của Two-Way Binding: [ngModel]="user.role" (ngModelChange)="user.role = $event"
