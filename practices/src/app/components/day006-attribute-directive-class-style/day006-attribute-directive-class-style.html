Phần 2

Đa Dạng Biểu Thức: [class]="classExpr" (String | Array | Object)

3 Dạng Biểu Thức Từ Tài Liệu
🎛️
3 định dạng của classExpr: Khi cần gán hoặc tính toán nhiều class cùng lúc, Angular hỗ trợ 3 dạng dữ liệu: 1. String (chuỗi cách nhau dấu cách: "class1 class2"), 2. Array String (mảng các chuỗi: ['class1', 'class2']), 3. Object Map (key là tên class, value là boolean: { class1: true, class2: false }).

🧪 Thử Nghiệm: Chuyển Đổi 3 Định Dạng Biểu Thức

Định dạng classExpr:
@if (classFormat() === 'string') {

} @else if (classFormat() === 'array') {
📦 Hộp Thử Nghiệm: Dùng [class]="Array String"
} @else {
📦 Hộp Thử Nghiệm: Dùng [class]="Object Map"
}
Live DOM Class Inspector:
class="{{ stringClassExpr() }}"
3 Dạng Biểu Thức classExpr TypeScript / HTML 
// 1. Dạng String (Chuỗi ghép nhau bởi dấu cách)
stringExpr = "demo-box box-rounded box-shadow";
<div [class]="stringExpr"></div>

// 2. Dạng Array String (Mảng các tên class)
arrayExpr = ['demo-box', 'box-rounded', 'box-shadow'];
<div [class]="arrayExpr"></div>

// 3. Dạng Object Map (Key là class, Value là boolean)
objectExpr = {
  'demo-box': true,
  'box-rounded': this.isRounded,
  'box-shadow': this.hasShadow
};
<div [class]="objectExpr"></div>
Khi nào dùng dạng nào? Dạng String thích hợp khi nối chuỗi class từ CSS framework (như Bootstrap). Dạng Array thích hợp khi lọc danh sách class động. Dạng Object Map là phổ biến và mạnh mẽ nhất khi mỗi class phụ thuộc vào một điều kiện logic riêng biệt!

Phần 3

Style Binding Kèm Đơn Vị Đo: [style.property.unit]="numericValue"

Tự động gắn đơn vị px, %, deg, rem
📐
Đặc quyền cú pháp của Angular: Thay vì phải cộng chuỗi thủ công (ví dụ: [style.width]="width + 'px'"), Angular cho phép viết trực tiếp hậu tố đơn vị: [style.width.%]="80", [style.height.px]="150", [style.fontSize.px]="18", hoặc [style.transform.deg]="45"! Giá trị truyền vào chỉ cần là kiểu number thuần túy.

Cú Pháp Style Binding Kèm Đơn Vị HTML 
<!-- 1. Đơn vị phần trăm (%) -->
<div [style.width.%]="boxWidthPercent"></div>
<div [style.opacity.%]="boxOpacityPercent"></div>

<!-- 2. Đơn vị pixel (px) -->

<!-- 3. Đơn vị rem, em, vh, vw -->

<div [style.minHeight.vh]="50"></div>

Phần 4

Multi-style Expressions & Studio Thiết Kế: [style]="styleExpr"

Hỗ trợ camelCase và dash-case
🎨
Gán đồng thời nhiều style: Cú pháp [style]="styleExpr" cho phép truyền một đối tượng (Object) chứa tập hợp các thuộc tính CSS. Trong object đó, tên thuộc tính có thể viết theo kiểu camelCase (ví dụ: backgroundColor) hoặc kiểu dash-case (ví dụ: 'background-color') đều được Angular hỗ trợ hoàn hảo!

Phần 5

Đối Chiếu & Khuyến Cáo: Native Binding vs NgClass / NgStyle

Khuyến nghị chính thức từ Angular
⚖️
Tại sao nên dùng [class] & [style] thay vì NgClass & NgStyle? Trước đây trong Angular cũ, NgClass và NgStyle là các directive bắt buộc. Tuy nhiên từ Angular 9 (Ivy engine) trở đi, bộ biên dịch Angular đã tối ưu vượt bậc cho cú pháp native binding [class] và [style], mang lại hiệu năng cao hơn, kích thước bundle nhỏ hơn và không cần import module!
Tiêu Chí So Sánh Cú Pháp Chuẩn: [class] & [style] Cú Pháp Cũ: [ngClass] & [ngStyle]
Khả năng Module Không cần import gì (Tích hợp sẵn trong core compiler) Phải import CommonModule / NgClass
Single class / Single style Cú pháp siêu ngắn: [class.active]="val", [style.width.px]="val" Không hỗ trợ (phải viết object map phức tạp)
Hậu tố đơn vị đo (Unit Suffix) Có hỗ trợ (.px, .%, .rem, .deg) Không hỗ trợ (phải tự nối chuỗi đơn vị)
Hiệu năng Change Detection Tối ưu trực tiếp qua Ivy DOM instruction Phải khởi tạo một Directive instance riêng cho mỗi phần tử
Khuyến nghị từ Angular Team Khuyên dùng cho 100% dự án mới Giữ lại chủ yếu để tương thích ngược (Legacy projects)
