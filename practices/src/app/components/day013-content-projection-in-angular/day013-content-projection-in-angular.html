Các Dạng Selector Hỗ Trợ HTML 
<!-- 1. Tag Selector: Khớp theo tên thẻ HTML hoặc Component -->
<ng-content select="header"></ng-content>
<ng-content select="app-user-avatar"></ng-content>

<!-- 2. Class Selector: Khớp theo tên CSS Class -->
<ng-content select=".card-header"></ng-content>

<!-- 3. Attribute Selector: Phổ biến nhất cho Design System -->
<ng-content select="[card-header]"></ng-content>
<ng-content select="[card-body]"></ng-content>

<!-- 4. Combine nhiều selector (dấu phẩy tương đương OR) -->
<ng-content select="[card-actions], .card-actions, footer"></ng-content>

<!-- 5. Catch-all Slot: Hứng mọi thẻ còn lại không match selector nào -->
<ng-content></ng-content>
Gợi ý kinh nghiệm: Nên ưu tiên sử dụng Attribute Selector (ví dụ: <div card-header>) thay vì CSS class selector. Cách này giúp phân tách rạch ròi giữa vai trò cấu trúc slot và phong cách định dạng CSS.

Bản Chất Eager Evaluation: Khi Nào ng-content Được Khởi Tạo?

Điểm khác biệt chí mạng với ng-template
⏱️
Câu hỏi phỏng vấn Angular thường gặp: Nếu component con bọc thẻ <ng-content> bên trong *ngIf="false" (đang đóng), thì component con bên trong có được khởi tạo không? CÓ! Trong Content Projection, component cha luôn khởi tạo ngay lập tức (Eagerly Evaluated) các element trước khi đem chiếu vào con. Hãy kiểm chứng log vòng đời ngay bên dưới!

Tiêu Chí <ng-content> (Day 13) <ng-template> (Day 14)
