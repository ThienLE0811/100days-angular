Kiến Thức Nền Tảng

2. Ba Thành Phần Cốt Lõi Của Angular DI

⚙️

1. Injector

Là đối tượng trung tâm chứa các API để tìm kiếm hoặc khởi tạo các instance. Khi component yêu cầu qua constructor, Injector sẽ kiểm tra xem đã có instance chưa hoặc dùng công thức để tạo mới.

📜

2. Provider

Là "Công thức / Bản thiết kế" hướng dẫn Injector biết cách tạo instance. Ví dụ: { provide: CartService, useClass: CartExtService } hoặc @Injectable({ providedIn: 'root' }).

📦

3. Dependency

Là đối tượng, giá trị hoặc hàm mà một class cần để thực thi nhiệm vụ của nó (ví dụ: đối tượng của class CartService mà ProductComponent cần dùng).

Cú Pháp Chuẩn Từ Day 15

2. Constructor Injection (Angular)

  constructor(public cartService: CartService) {}
}
3. Override Provider bằng useClass 
@Component({
  providers: [
    { provide: CartService, useClass: CartExtService }
  ]
})
