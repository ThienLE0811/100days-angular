Sức mạnh của useExisting: Ta tạo BsTabGroupComponent với UI Bootstrap hoàn toàn mới. Tổng Hợp Cú Pháp

3. Bốn Cú Pháp Cung Cấp Provider (Provider Syntax)

1. useClass

Tráo đổi Class

Cung cấp một class khác thay thế cho token. Ví dụ: inject LoggerService nhưng nhận instance của TimestampLoggerService.

Kết quả log: {{ logger.log('Kiểm tra useClass') }}
2. useExisting

Tạo Alias / Bí danh

Trỏ một Token đến một instance đã tồn tại sẵn mà không tạo instance mới (như cách BsTabGroupComponent trỏ về TabGroupComponent).

Minh họa: provide: TabGroupComponent, useExisting: BsTabGroupComponent
3. useFactory

Hàm tạo động

Gọi một hàm factory để tính toán và trả về giá trị (có thể inject thêm dependencies thông qua mảng deps).

Lời chào động theo giờ:
{{ greeting.message }}
Tính lúc: {{ greeting.greetingTime }}
4. useValue

Giá trị tĩnh / Config

Cung cấp một giá trị cố định, object config hoặc hằng số thông qua một InjectionToken.

App Config: {{ appConfig.appName }} (v{{ appConfig.version }})
Môi trường: {{ appConfig.environment }}

Cú Pháp Trọng Tâm Day 16

1. Child injects Parent 
export class TabPanelComponent {
  constructor(private tabGroup: TabGroupComponent) {}
  ngOnInit() { this.tabGroup.addTabPanel(this); }
  ngOnDestroy() { this.tabGroup.removeTabPanel(this); }
}
2. useExisting với forwardRef 
const BsTabGroupProvider = {
  provide: TabGroupComponent,
  useExisting: forwardRef(() => BsTabGroupComponent),
};
3. Khai báo 4 Provider Syntax 
providers: [
  { provide: ClassA, useClass: ClassB },
  { provide: ClassA, useExisting: ClassC },
  { provide: TokenA, useFactory: myFactory },
  { provide: TokenB, useValue: configObj }
]
