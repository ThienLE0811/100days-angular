3. Pure vs Impure Pipe & Cơ Chế Change Detection

⚠️
Quy tắc quan trọng từ Day 18: Mặc định Pipe luôn là Pure (pure: true). Angular chỉ chạy lại Pure Pipe khi có sự thay đổi giá trị nguyên thủy (Primitive) hoặc thay đổi Reference của Object/Array. Nếu bạn dùng users.push() (mutate mảng), reference không đổi → Pure Pipe sẽ KHÔNG chạy lại!

Bản Chất Kỹ Thuật

4. So Sánh Bản Chất: Pure Pipe vs Impure Pipe

Đặc điểm Pure Pipe (Mặc định) Impure Pipe (pure: false)
Cú pháp khai báo @Pipe({ name: '...', pure: true }) @Pipe({ name: '...', pure: false })
Điều kiện kích hoạt Chỉ khi giá trị nguyên thủy hoặc Object Reference thay đổi. Kích hoạt trong MỌI chu kỳ Change Detection (bấm phím, click, timer,...).
Hiệu năng (Performance) Rất cao (Check reference siêu nhanh) Tốn kém (Nếu data lớn sẽ làm giật lag giao diện)
Khuyến nghị từ Angular Ưu tiên sử dụng 99% trường hợp kết hợp với Immutability. Hết sức cẩn trọng, chỉ dùng khi bất khả kháng hoặc với AsyncPipe.
Kiến Trúc Chuyên Sâu

5. Sáu Tác Dụng Vượt Trội Của Pipes Trong Angular

Tư duy Senior Angular

Ngoài việc nhận input và trả ra output hiển thị, Pipe là giải pháp kiến trúc cốt lõi giúp ứng dụng Angular đạt hiệu năng tối đa và sạch sẽ:

⚡

1. Tối Ưu Hiệu Năng (Memoization / Caching)

Pure Pipe tự động lưu đệm (cache) kết quả. Phương thức transform() chỉ chạy lại khi Input thay đổi tham chiếu. Tránh hoàn toàn việc hàm bị chạy lại hàng trăm lần trong mỗi chu kỳ Change Detection.

🛡️

2. Quản Lý Async & Chống Rò Rỉ Bộ Nhớ (Memory Leak)

AsyncPipe tự động subscribe khi render và tự động unsubscribe khi component destroy. Không cần viết ngOnDestroy hay quản lý Subscription thủ công.

🎯

3. Tách Biệt Trách Nhiệm (Separation of Concerns - SRP)

Component chỉ tập trung vào Logic nghiệp vụ (gọi API, State Management), còn Pipe chịu trách nhiệm riêng về định dạng hiển thị (Presentation Formatting).

🔄

4. Tái Sử Dụng Cao & Chuẩn DRY (Don't Repeat Yourself)

Viết một lần, sử dụng ở bất kỳ template nào trong toàn bộ ứng dụng mà không cần copy-paste hàm helper vào từng component.

🔗

5. Ghép Nối Linh Hoạt (Pipe Chaining)

Dễ dàng kết hợp nhiều bộ lọc từ trái qua phải: isoDate | date:'medium' | uppercase mà không phải lồng ghép hàm phức tạp như uppercase(date(val)).

🧪

6. Cực Kỳ Dễ Viết Unit Test (Testability)

Pipe là Class thuần túy (POJO) với method transform(). Viết Unit Test trực tiếp bằng new MyPipe().transform(...) mà không cần khởi tạo DOM hay TestBed.

🔥 Thử Nghiệm Trực Quan: Gọi Hàm Trong HTML vs Pure Pipe

Gọi Method trong HTML (Bad Practice)

{{ formatPriceWithMethod(samplePrice) }}

Kết quả: {{ formatPriceWithMethod(samplePrice) }} Đã chạy: {{ methodExecutionCount }} lần
• Bị gọi lại trong MỌI chu kỳ Change Detection (dù dữ liệu không hề đổi)!
Dùng Pure Pipe (Best Practice)

{{ samplePrice | currency:'USD' }}

Kết quả: {{ samplePrice | currency : 'USD' : 'symbol' : '1.2-2' }} Memoized: Tối ưu cache
• Chỉ chạy khi tham chiếu giá trị thay đổi, tiết kiệm tài nguyên CPU!
