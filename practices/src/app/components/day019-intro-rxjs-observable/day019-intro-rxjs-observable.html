Bản Chất Bất Đồng Bộ

2. So Sánh Bản Chất: Promise vs Observable

Tiêu chí Promise Observable (RxJS)
Số lượng giá trị Chỉ phát ra 1 giá trị duy nhất (Single value). Phát ra nhiều giá trị theo thời gian (0 đến vô hạn).
Thời điểm thực thi Eager (Chạy ngay khi tạo `new Promise`). Lazy (Chỉ chạy khi có người gọi `.subscribe()`).
Khả năng hủy (Cancellation) Không thể hủy giữa chừng một cách dễ dàng. Dễ dàng hủy bất kỳ lúc nào bằng subscription.unsubscribe().
Khả năng biến đổi Chỉ có `.then()`, `.catch()`, `.finally()`. Hơn 100+ Operators phong phú (map, filter, switchMap, debounce...).

4. Vòng Đời Observable: Next, Error, Complete & Quy Tắc Đóng Stream

Theo đặc tả của RxJS: Trong một Observable Execution, có thể có từ 0 đến vô hạn Next notifications. Nhưng chỉ có thể có duy nhất 1 Error HOẶC 1 Complete notification. Một khi Error hoặc Complete đã được gửi đi, stream sẽ đóng vĩnh viễn và không có dữ liệu nào được phát tiếp nữa.

Cú Pháp Trọng Tâm Day 19

1. Tạo Observable với Teardown 
const obs = new Observable(observer => {
  const id = setTimeout(() => {
    observer.next('Hello RxJS');
    observer.complete();
  }, 1000);
  return function unsubscribe() {
    clearTimeout(id);
  };
});
2. Throttle Event với RxJS 
fromEvent(btn, 'click').pipe(
  throttleTime(500),
  scan(count => count + 1, 0)
).subscribe(c => console.log(c));
3. Observer Callbacks Object 
obs.subscribe({
  next: (val) => console.log(val),
  error: (err) => console.error(err),
  complete: () => console.log('Done')
});
4. Gộp Subscription bằng .add() 
const parent = interval(500).subscribe();
const child = interval(700).subscribe();
parent.add(child);
// Hủy cả hai cùng lúc:
parent.unsubscribe();
