📸 Snapshot

route.snapshot.paramMap

Chỉ đọc đúng 1 lần lúc component được tạo.

slug: {{ snapshotSlug }}

@if (snapshotArticle; as article) {
{{ article.title }}
} @else {

Không tìm thấy bài viết.

}

🔄 Observable

route.paramMap

Emit giá trị mới mỗi khi route thay đổi.

slug: {{ observableSlug() }}

@if (observableArticle(); as article) {
{{ article.title }}
} @else {

Không tìm thấy bài viết.

}

👉 Bấm sang một bài viết khác ở danh sách phía trên (cùng route config :slug) — Angular Router sẽ tái sử dụng component này thay vì tạo mới. Quan sát: ô Snapshot đứng yên, ô Observable cập nhật đúng bài viết mới.
