Trang /admin bên dưới được khai báo với loadComponent — tương đương loadChildren trong ứng dụng NgModule cũ. Component AdminPanel (kèm ReactiveFormsModule) sẽ nằm trong một file JS riêng biệt, chỉ được browser tải về khi bạn thực sự điều hướng tới đó — không tính vào bundle chính khi mở app.

🔍 Mở DevTools → tab Network, lọc theo "chunk", rồi bấm nút "Vào trang Admin" bên dưới — bạn sẽ thấy một request JS mới xuất hiện đúng lúc đó (dev server có thể gộp thành 1 request tên dài kèm hash).

Trạng thái bundle Admin: @switch (adminChunkStatus()) { @case ('idle') { ⏳ Chưa tải } @case ('loading') { 📡 Đang tải (mô phỏng mạng chậm ~2.5s)... } @case ('ready') { ✅ Đã sẵn sàng ({{ adminChunkElapsedMs() }}ms) } }
🔧 Vào trang Admin

So sánh 2 kịch bản: (1) Bấm thẳng "Vào trang Admin" mà chưa preload — quan sát độ trễ ~2.5s trước khi giao diện admin hiện ra (thanh loading ở trên sẽ chạy). (2) Bấm "Preload Admin ngay" trước, đợi tới khi trạng thái chuyển "Đã sẵn sàng", rồi mới bấm "Vào trang Admin" — lần này sẽ vào ngay lập tức, không còn độ trễ.
